# almodhesh-audio

أتمتة تحويل النصوص العربية إلى ملفات صوتية MP3 باستخدام ElevenLabs و GitHub Actions.

## هيكل المشروع

| المسار | الوصف |
|---|---|
| `texts/` | ضع هنا النصوص العربية، كل نص في ملف `.txt` (ترميز UTF-8) |
| `audio/` | ملفات MP3 الناتجة + `manifest.json` (سجل ما تم توليده) |
| `scripts/generate_audio.py` | سكربت التحويل (بايثون، بدون مكتبات خارجية) |
| `tests/` | اختبارات لا تتصل بـ ElevenLabs ولا تستهلك رصيدًا |
| `.github/workflows/generate-audio.yml` | سير العمل في GitHub Actions |

## التشغيل التلقائي اليومي (مفعّل)

- يعمل يوميًا الساعة **6:00 صباحًا بتوقيت أوتاوا** (America/Toronto)، صيفًا وشتاءً.
  لأن GitHub لا يقبل إلا توقيت UTC، توجد جدولتان (10:00 و 11:00 UTC)، وخطوة تحقق تسمح بتشغيل
  الجدولة المطابقة لـ 6:00 في أوتاوا فقط وتتخطى الأخرى فورًا.
- يحوّل النصوص الجديدة أو المعدّلة فقط، ويحفظ ملفات MP3 و `audio/manifest.json` و `audio/usage.json` في المستودع تلقائيًا.
- قد يتأخر بدء التشغيل المجدول بضع دقائق عند ازدحام خوادم GitHub.

## الأمان وحماية الرصيد

- المفتاح يُقرأ فقط من السر `ELEVENLABS_API_KEY` في GitHub Secrets، ولا يُكتب في أي ملف.
- **حد يومي 1000 حرف** (بحسب يوم أوتاوا)، يشمل التشغيل المجدول واليدوي معًا، ويُسجَّل في `audio/usage.json`.
  لتغييره عدّل `DAILY_MAX_CHARS` في ملف سير العمل. النص الأطول من المتاح يُؤجَّل ولا يُقطع.
- قبل التوليد يُفحص الرصيد المتبقي: إن لم يكفِ **أو تعذّر فحصه** تتوقف التشغيلة دون استهلاك.
- النص الذي وُلِّد سابقًا ولم يتغير يُتخطى تلقائيًا (بصمة SHA-256 في `audio/manifest.json`).
- لا تعمل تشغيلتان معًا؛ أي تشغيلة جديدة تنتظر انتهاء السابقة.

### صلاحيات المفتاح المطلوبة

إذا كان المفتاح مقيّد الصلاحيات (Restricted key) في ElevenLabs فيلزمه:

- **Text to Speech**: للتحويل.
- **User → Read** (`user_read`): لقراءة الرصيد. بدونها يتوقف التحويل احتياطيًا.

## التشغيل اليدوي

من **Actions ← Generate Arabic audio (ElevenLabs) ← Run workflow**، واختر `mode`:

| الوضع | ماذا يفعل | يستهلك رصيدًا؟ |
|---|---|---|
| `dry-run` (الافتراضي) | يعرض ما سيُحوَّل وعدد الأحرف | لا |
| `check-balance` | يتحقق من المفتاح وصلاحية قراءة الرصيد ويعرض الرصيد | لا |
| `generate` | يحوّل ويحفظ النتائج في المستودع | نعم (ضمن الحد اليومي) |

## الإعدادات الاختيارية (Repository variables)

من **Settings ← Secrets and variables ← Actions ← Variables**:

- `ELEVENLABS_VOICE_ID`: معرّف الصوت (الافتراضي صوت جاهز من مكتبة ElevenLabs).
- `ELEVENLABS_MODEL_ID`: النموذج (الافتراضي `eleven_multilingual_v2` الداعم للعربية).

## التشغيل المحلي

```bash
python3 scripts/generate_audio.py --dry-run
python3 -m unittest discover -s tests -v
```
