# المدهش – Almodhesh

موقع يومي لتعلّم الإنجليزية الأمريكية من أخبار اليوم: ستة أخبار مبسّطة، ترجمة عربية، نطق أمريكي، و20 كلمة جديدة.
من **الأحد إلى الخميس** الساعة **6:00 بتوقيت أوتاوا** يُعدّ درس جديد ويُنشر تلقائيًا على GitHub Pages، دون الحاجة لتشغيل أي جهاز.

| اليوم | ما يظهر في الموقع | الاستهلاك |
|---|---|---|
| الأحد – الخميس | درس جديد + اختبار اليوم (5 أسئلة) | Claude + ElevenLabs (حتى 1000 حرف) |
| الجمعة والسبت | مراجعة: اختبار الأسبوع (10 أسئلة من دروس الأيام الخمسة) | لا شيء |

الاختباران يُبنيان من الدروس المحفوظة في الموقع، ويُحسبان في سلسلة الأيام 🔥.

## كيف يعمل

```

  الجزيرة، ذا ناشيونال…)     + ترجمة كل كلمة)       السياسة، الطول)
```

### سياسة اختيار الأخبار (دائمة)

- **المنطقة**: كل الأخبار الستة عن الشرق الأوسط وشمال أفريقيا (MENA).
- **التنويع**: أربعة مجالات مختلفة على الأقل من: الاقتصاد، التكنولوجيا، الصحة، التعليم، العلوم، الرياضة، الثقافة، الأحداث المهمة.
- **الحروب والسياسة**: خبر واحد كحد أقصى، وبصياغة محايدة دون تفاصيل عنيفة.
- **المصادر**: خلاصات وكالات وصحف موثوقة، ورابط الخبر الأصلي يُؤخذ من المصدر نفسه.
- **اللغة**: جمل إنجليزية أمريكية بمستوى A2–B1، وترجمة عربية فصيحة، و20 كلمة من أخبار اليوم.
- الدرس الذي يخالف السياسة يُرفض آليًا ويُطلب تصحيحه؛ وإن لم يُصحَّح لا يُنشر ويبقى آخر درس صالح.
- المصادر في `FEEDS` داخل `scripts/daily_lesson.py`.

| المسار | الوصف |
|---|---|
| `site/` | الموقع (نسخة طبق الأصل من التصميم والوظائف الأصلية) |
| `site/lessons/YYYY-MM-DD.json` | درس كل يوم |
| `site/lessons-data.js` | يُولَّد تلقائيًا من ملفات الدروس — لا يُعدَّل يدويًا |
| `site/audio/YYYY-MM-DD/` | تسجيلات الأخبار والكلمات |
| `scripts/daily_lesson.py` | خط الدرس اليومي كاملًا |
| `scripts/build_site_data.py` | بناء بيانات الموقع من ملفات الدروس |
| `scripts/elevenlabs_history.py` | تحديد الصوت المستخدم سابقًا (قراءة فقط) |
| `scripts/generate_audio.py` | أداة تحويل النصوص العربية في `texts/` (يدوي فقط) |
| `audio/usage.json` | سجل الأحرف المستهلكة يوميًا (مشترك بين الأداتين) |
| `logs/ai-usage.json` | سجل رموز Claude وتكلفتها التقديرية |

## المستويات الثلاثة

| المستوى | CEFR | النص |
|---|---|---|
| مبتدئ · Beginner | A1–A2 | جملة قصيرة (30–95 حرفًا)، كلمات شائعة، قواعد بسيطة |
| متوسط · Intermediate | B1–B2 | جملة طبيعية (60–140 حرفًا)، مفردات أوسع |
| متقدم · Advanced | C1–C2 | جملة أو جملتان (90–230 حرفًا)، لغة مهنية ومفردات متقدمة |

- تُجلب الأخبار **مرة واحدة**، ويستخرج طلب واحد **الحقائق فقط**؛ ثم يكتب طلب لكل مستوى نصّه من هذه الحقائق بكلماته
  (لا يرى نص المقال)، فتتطابق الحقائق والمصادر والروابط في المستويات الثلاثة.
- لكل مستوى: 6 جمل مع الترجمة، 20 كلمة مناسبة، 3 أسئلة فهم (تظهر في اختبار اليوم)، ويستخدمه اختبار الأسبوع وكروت الكلمات.
- المستوى المختار يُحفظ في المتصفح؛ لكل مستوى ملف بيانات `site/lessons-data-<level>.js`. الدروس القديمة تظهر كما هي في المستويات الثلاثة.
- كل درس جديد يحتفظ أيضًا بنسخة المستوى المتوسط بالصيغة القديمة، فيعمل الرجوع إلى النسخة السابقة دون أعطال.

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `LESSON_LEVELS` | الثلاثة | المستويات التي تُكتب نصوصها بـ Claude (غير المفعّل يعرض نص المتوسط) |
| `AUDIO_LEVELS` | `intermediate` | المستويات التي تُسجَّل بـ ElevenLabs؛ البقية بصوت المتصفح الأمريكي مجانًا |

أي نص سبق تسجيله (في أي درس أو مستوى) يُعاد استخدام تسجيله ولا يُسجَّل مرة أخرى.

## الحماية

- **الحد اليومي 1000 حرف صوتي** يُحسب بيوم أوتاوا، ويُفحص العدد الفعلي قبل كل توليد. إن لم يكفِ المتاح، تُولَّد القصص أولًا ثم الكلمات بقدر ما يسمح الحد، والباقي يعمل بصوت المتصفح.
- **الرصيد**: يُفحص رصيد ElevenLabs قبل التوليد؛ إن لم يكفِ أو تعذّر فحصه لا يُولَّد شيء.
- **لا تكرار**: لا يُعاد إعداد درس موجود، ولا يُعاد توليد تسجيل موجود (بصمة في `site/audio/manifest.json`).
- **آخر درس صالح**: إن فشل إعداد الدرس أو لم يجتز الفحوص، لا يُنشر شيء ويبقى آخر درس صالح.
- **الروابط حقيقية**: رابط كل خبر يؤخذ من خلاصة المصدر نفسها، وليس مما يكتبه النموذج.
- **المفاتيح** في GitHub Secrets فقط: `ANTHROPIC_API_KEY` و `ELEVENLABS_API_KEY`.
- لا تعمل عمليتا تحويل في الوقت نفسه.

## الإعدادات (Settings ← Secrets and variables ← Actions)

| الاسم | النوع | الوصف |
|---|---|---|
| `ELEVENLABS_API_KEY` | Secret | مفتاح ElevenLabs (صلاحيات: Text to Speech، User → Read، و Speech History → Read لتحديد الصوت) |
| `ANTHROPIC_API_KEY` | Secret | مفتاح Claude لإعداد الدروس |
| `LESSON_MODEL` | Variable | نموذج Claude (الافتراضي الاقتصادي `claude-haiku-5-5`؛ للجودة الأعلى `claude-sonnet-5-5`) |
| `ELEVENLABS_LESSON_VOICE_ID` | Variable | معرّف الصوت الأمريكي |
| `ELEVENLABS_LESSON_MODEL_ID` | Variable | نموذج ElevenLabs (الافتراضي `eleven_multilingual_v2`) |

## التشغيل اليدوي

**Actions ← Daily lesson (Almodhesh) ← Run workflow**:

| الوضع | ماذا يفعل | التكلفة |
|---|---|---|
| `news-check` | يجلب الأخبار من المصادر ويعرضها | مجاني |
| `voice-info` | يحدد صوت درس 21 نوفمبر من سجل ElevenLabs | مجاني |
| `run` | يعدّ درس اليوم ويولّد صوته وينشره (هذا ما يحدث يوميًا تلقائيًا) | Claude + حتى 1000 حرف |
| `audio-only` | يكمل الصوت الناقص لأحدث درس ضمن الحد اليومي | ElevenLabs فقط |
| `deploy-only` | يعيد نشر الموقع | مجاني |

## التثبيت كتطبيق على Windows

افتح رابط الموقع في Chrome أو Edge، ثم اضغط أيقونة **التثبيت** في شريط العنوان (أو القائمة ⋮ ← **Install Almodhesh – المدهش**).
سيظهر التطبيق بأيقونته في قائمة ابدأ؛ لإضافته إلى سطح المكتب: كليك يمين على أيقونته ← **Pin/Send to Desktop**، أو من Edge: **Apps ← Create desktop shortcut**.
